# Survey API

REST API for creating and managing surveys, built with Node.js and TypeScript.

This project focuses on applying software engineering practices such as **TDD, Clean Architecture, SOLID, DDD, Design Patterns, and automated testing**.

## Technologies

* Node.js
* TypeScript
* Express
* Jest
* MongoDB
* Mongoose
* Docker
* Swagger / OpenAPI
* GitHub Actions

> The technologies are being introduced incrementally throughout the development of the project.

## Architecture

The project follows **Clean Architecture**, with a focus on:

* Separation of concerns
* Dependency inversion
* Low coupling
* Testability
* Maintainability

## Testing

Development follows **Test-Driven Development (TDD)**:

```text
Red → Green → Refactor
```

The project includes unit, integration, and end-to-end tests.

## About the Project

This project is based on the course **Node.js Avançado com TDD, Clean Architecture e TypeScript**, by Rodrigo Manguinho.

The architecture and development approach follow the concepts presented in the course, while the implementation is adapted to newer versions of the technologies and dependencies whenever possible.

The goal is to use the project not only to follow the course, but to understand and practice the software engineering concepts behind the implementation.

Original project: https://github.com/rmanguinho/clean-ts-api

## Running Locally

### Requirements

* Node.js
* npm
* Docker

### Installation

```bash
git clone https://github.com/Kianelc/survey-api.git
cd survey-api
npm install
```

### Tests

```bash
npm test
```

### Run

```bash
npm start
```

> Additional configuration will be documented as the project evolves.
